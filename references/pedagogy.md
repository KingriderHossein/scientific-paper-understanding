# Adaptive Learning Rules

## Goal

Teach only what unlocks the next important layer of the paper.

## Minimal Prerequisite Frontier

For the current target node, identify concepts that are both necessary and not already demonstrated as understood.

Prefer 3-7 blockers. Separate them mentally into:
- domain/biology concepts;
- study-design/evidence concepts;
- statistics/mathematics;
- computational/method concepts.

Do not expose all categories unless useful.

Example:

`count data -> negative binomial -> dispersion -> shrinkage -> DESeq2 inference`

If earlier concepts are already understood, start at the first true blocker.

## Mastery States

Use only as internal guidance:
- unknown;
- exposed;
- partial;
- functional understanding.

Do not claim mastery from one yes/no answer.

## Explanation Ladder

When needed:
1. intuitive meaning;
2. formal meaning;
3. where it appears in this paper;
4. what result/figure/method it unlocks;
5. one example if useful;
6. optional comprehension check.

Do not repeat all layers when one is enough.

## Next Best Learning Action

Prioritize an item when:
1. it blocks a central result/method;
2. it unlocks several later concepts;
3. it has low enough cognitive cost;
4. it connects directly to a visible paper object.

This is qualitative, not a numerical formula.

## Figures as Learning Anchors

Use a key figure after prerequisites are sufficient. Explain the question the figure answers before visual details.

## Evidence Literacy as a Prerequisite

When a user's misunderstanding is about evidence rather than terminology, teach the boundary first. Examples:
- association versus causation;
- protocol versus result;
- primary versus secondary analysis;
- in-silico versus experimental validation;
- discrimination versus calibration;
- qualitative theme versus prevalence;
- animal/model-system evidence versus human clinical evidence.

## Comprehension Checks

Use short checks only when they improve learning. Good checks ask the learner to explain a logical link, interpret an axis, distinguish claim from evidence, or predict what a method step does.

Do not append quizzes automatically.

## Beginner Safety

For beginners:
- reduce jargon density;
- introduce technical terms in context;
- never simplify past scientific correctness;
- separate `needed now` from advanced detail;
- show connections rather than summarizing sections independently.

## Advanced Users

Skip basics when competence is demonstrated. Focus on assumptions, evidence, failure modes, and interpretation.
